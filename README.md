# 課後遊樂場

一個單檔網頁遊戲平台，11 款遊戲全部內嵌在 `index.html` 裡，不需要伺服器、不依賴任何外部資源，離線也能玩。

**線上試玩：** https://casper-1112.github.io/arcade/

## 平台功能

- 今日精選（每天自動換一款）、隨機開一款
- 分類籤條、關鍵字搜尋（名稱／分類／標籤）
- ♥ 收藏、最近玩過、遊玩次數與各難度最高分
- 三種難度、全螢幕
- 鍵盤、滑鼠、手機觸控都支援

所有紀錄以 `localStorage` 存在玩家自己的瀏覽器裡，不會上傳。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，或部署到任何靜態網頁空間（GitHub Pages / Cloudflare Pages / 內部 IIS 都可以）。

## 技術

- 純 HTML + CSS + JavaScript，無框架、無建置流程、無外部相依
- 2D 遊戲以 Canvas 繪製；三角洲撤離為自製光線投射（raycasting）3D 引擎
- 音效以 Web Audio API 即時合成
- 方塊POP！以同源寫入載入內嵌的獨立頁面，與平台互不干擾
